──────────────────────────────────────────────────────────────
  实验3 DMA：谁在搬运数据？
──────────────────────────────────────────────────────────────
  传输数据量: 512.0 MB

  [无 DMA（PIO 模式）—— CPU 亲自搬运]
    阶段1 搬运数据 .....    49.75 ms
    阶段2 执行计算 .....    54.04 ms
    总耗时 .............   103.79 ms   (CPU 全程忙碌)

  [有 DMA —— CPU 发起传输后立即返回]
    CPU 发起传输 .......     0.00 ms
    CPU 并行执行计算 ...    54.00 ms
    等待传输完成(中断) .     0.00 ms
    总耗时 .............    54.00 ms   (CPU 几乎零等待)

  对比：DMA 模式节省    49.79 ms（48.0%）
  说明：真实 DMA 由硬件控制器（磁盘/网卡/显卡）直接读写内存，
        CPU 只配置描述符并响应完成中断；本实验用后台线程模拟该机制。
